앱 사용설명서

최신 버전

1. 한 줄로 보면

  1. 이름 적기 → 충전소·거점 고르기
  2. 필수 사진 찍기
  3. MCCB용량·계량기번호만 숫자 크게 찍기
  4. 확인 후 거점 저장
  5. 내역에서 일지 엑셀 내려받기
보고는 「엑셀 일지 + 거점별 사진」입니다. 손으로 쓰던 표와 같은 열입니다.

2. 시작하기

  1. 홈에서 본인 이름을 적습니다. 없으면 시작·완료가 안 됩니다.
  2. 지역 → 시/군 → 충전소를 고릅니다.
  3. 거점을 누르고 점검 시작을 누릅니다.

3. 사진 찍는 법

  • 카메라는 닫지 말고, 위 제목을 누르거나 좌우로 넘겨 항목만 바꿉니다.
  • 1~5, 8번은 필수입니다. (전압·저항·절연·충전기·배전반·전체샷)
  • 6. MCCB용량 · 7. 계량기번호는 일지에 들어가는 칸입니다.
  • 배전반 전체가 아니라, 50A·75A 글자 / 계량기 번호만 화면 절반 이상 크게 찍으세요.
  • 줌+, 핀치, 위아래 드래그로 키울 수 있습니다.
멀리서 찍은 뒤 나중에 확대하면 글자가 뭉개져 자동 입력이 안 됩니다. 찍을 때 숫자만 크게 찍으세요.

4. 자동으로 들어가는 것

  • 국소명, 거점, 충전기 수, 충전기 번호(1~4, 5~8…), 비고(장소)
  • MCCB용량·계량기번호는 6·7번 확대 사진에서 읽습니다.
  • 용량은 현장에서 거의 50A 또는 75A입니다.
  • 전압·저항·절연 숫자는 일지에 안 넣습니다. 사진만 있으면 됩니다.
  • 접지저항 칸은 있어도 되고, 비워 둬도 저장됩니다.

5. 사진 · 거점 저장

  1. 찍은 사진은 바로 이 폰(앱)에만 저장됩니다. 구글 드라이브에는 아직 안 올라갑니다.
  2. 잘못 찍으면 × 또는 다시 찍기로 지우면 됩니다. 드라이브에 잘못된 장이 쌓이지 않습니다.
  3. 이 거점 점검 완료 → 확인 화면에서 MCCB·제조번호를 봅니다.
  4. 이 거점 저장을 누르면 그때 사진이 드라이브로 올라가고, 시트에도 기록됩니다.
같은 거점을 다시 저장하면 시트 같은 줄이 덮어씌워집니다. 거점을 바꾸면 MCCB·계량기 칸은 비워집니다.

6. 그날 보고 (엑셀)

  1. 아래 메뉴 내역으로 갑니다.
  2. 동기화 후 오늘 점검일지를 한 번 누릅니다.
  3. 일지 엑셀 내려받기를 누릅니다.
  4. 파일 열: 국소명, 거점, 충전기수, 충전기번호, MCCB용량, 접지저항, 계량기번호, 비고
카톡으로 보낼 때는 「오늘 점검 카톡으로 보내기」 zip을 쓰면 일지·사진 폴더가 같이 갑니다.

7. 오늘·이번주 확인 / 동선

  • 홈의 오늘·이번주·누적을 누르면 어디를 했는지 목록이 나옵니다.
  • 진행률을 누르면 지역별로 얼마나 됐는지 보입니다.
  • 기록은 구글 시트 하나입니다. 홈의 팀 동기화를 누르면 그 시트 최신이 이 폰에 맞춰집니다.
  • 다른 사람도 각자 동기화(또는 앱을 다시 열기)하면 모두가 같은 숫자를 봅니다. 한 사람만 눌러서는 남의 폰이 자동으로 바뀌진 않습니다.
  • 동선에서 지역만 고르면 그 지역 전체가 나오고, 정렬이 가까운 순(GPS)이면 지금 위치에서 가까운 곳부터 보입니다.
  • 시/군 버튼으로 좁힐 수도 있습니다.
  • 각 충전소에 주소 복사 · 카카오맵 · 네이버맵이 있습니다. 복사한 주소를 내비에 붙여넣어도 됩니다.
  • 조를 나눠 다니면 거점 잠금은 쓰지 않습니다.

8. 자주 막히는 것

  • 칸이 비면 → 6·7번을 숫자만 크게 다시 찍거나, 확인 화면에서 직접 적습니다.
  • 지하에서 판독이 안 되면 → 인터넷이 한 번 필요합니다. 안 되면 두 칸만 수기 입력하세요.
  • 사진이 안 올라가면 → 업로드가 끝난 뒤 다시 완료를 누르세요.
  • 화면 위에 「새 버전」이 뜨면 → 강제 새로고침을 누르세요.
  • 가까운 순이 안 되면 → 설정에 있는 구글 스크립트를 새 버전으로 한 번 배포하세요.
